# Model Artifacts

This document details the important model checkpoints generated by SATYA, their paths, purposes, and current scientific status.

All models should be placed in the `models/` directory. Important models will be tracked via Git LFS.

## Image Forensics

### 1. `models/image_ntire_unfrozen/best_image_model.pth`
- **Model:** EfficientNet-B0 (Binary Classifier)
- **Dataset:** Derived from NTIRE 2026 (or equivalent baseline dataset).
- **Purpose:** Identifies if an image is Real (0) or Manipulated/Fake (1).
- **Status:** Integrated into the pipeline.
- **Scientific Validation:** Yes (baseline).
- **Important Limitations:** This is a baseline checkpoint. It works well on its test set but may not generalize broadly to unseen generative architectures or novel manipulation techniques.

## Audio Forensics

### 1. (Expected) `models/audio/asvspoof_model.pth`
- **Model:** AudioResNet (or similar CNN-based architecture)
- **Dataset:** ASVspoof 2019 Logical Access (LA)
- **Purpose:** Distinguishes between bona fide (real) speech and spoofed (TTS/VC) speech.
- **Status:** **INTERMEDIATE RESULT.**
- **Scientific Validation:** **PENDING.** The ASVspoof EVAL set results are not yet finalized.
- **Important Limitations:** This checkpoint is an intermediate result from development training and must **NOT** be described or used as a final, general-purpose deepfake audio detector. Its performance in real-world, unconstrained scenarios is unverified until the formal ASVspoof EVAL results are complete.
